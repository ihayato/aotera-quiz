# 項目と形式

## 1問の項目（`data/all.jsonl`）

| 項目 | 中身 |
|---|---|
| `id` | 問題の番号（16文字）。版が変わっても同じ問題は同じ番号 |
| `genre` | ジャンル（下の表） |
| `format` | 形式（下の表） |
| `difficulty` | 難しさ。1（やさしい）〜5（むずかしい） |
| `body` | 問題の中身。形式ごとに形が違います（下の「形式ごとの中身」） |
| `answer` | 答え。○×は `true` / `false`、順番当ては並び（配列）、ほかは文字 |
| `note` | ×の○×だけに付く「正しくは」。ほかは `null` |
| `source_url` | 確かめた資料 |
| `as_of` | 確かめた日 |
| `expires` | 確かめ直す目安の日。記録や制度で答えが変わることがあるので、スポーツは全問、社会は一部に付いています。ほかは `null` |
| `version` | 問題の版。直すと1つ増えます |

選択肢・文字・並べるものは、問題ごとに決まった並びで混ぜてあります。最初の並びが正解と同じになることはないので、出題するときは毎回混ぜ直すのがおすすめです。

## ジャンル

| `genre` | ジャンル |
|---|---|
| `bunkei` | 文系の学問（歴史・文学・言葉・漢字など） |
| `life` | ライフスタイル（食べ物・暮らし・身の回りの物など） |
| `sports` | スポーツ |
| `anige` | アニメ・ゲーム（特撮・漫画を含む） |
| `rikei` | 理系の学問（理科・数学・技術など） |
| `shakai` | 社会（地理・政治・経済・法律など） |

## 形式ごとの中身

### ○×（`maru`）

```json
"body": { "text": "『万葉集』は、平安時代に作られた最初の勅撰和歌集である。" },
"answer": false,
"note": "最初の勅撰和歌集は、905年に醍醐天皇が編纂を命じた『古今和歌集』。"
```

### 四択（`yontaku`）

```json
"body": {
  "text": "『ストリートファイターII』で、リュウの代表的な飛び道具技は?",
  "choices": ["竜巻旋風脚", "波動拳", "昇龍拳", "サマーソルトキック"]
},
"answer": "波動拳"
```

### 連想（`rensou`）

ヒントは5つ。前のほうほど難しく、あとになるほど分かりやすくなります。ゲームでは1つずつ見せています。

```json
"body": {
  "hints": ["1921年ノーベル物理学賞", "受賞理由は光電効果の説明", "1905年に論文を連発", "E=mc²を導いた", "相対性理論の提唱者"],
  "choices": ["ハイゼンベルク", "プランク", "ボーア", "アインシュタイン"]
},
"answer": "アインシュタイン"
```

### 並べ替え（`narabe`）

`tiles` を全部使って答えを作ります。

```json
"body": {
  "text": "1995年放送のテレビアニメ『新世紀エヴァンゲリオン』で、初号機のパイロットを務める主人公の少年は?(ひらがなで、姓名続けて)",
  "tiles": ["じ", "り", "し", "い", "ん", "か"]
},
"answer": "いかりしんじ"
```

### 文字パネル（`panel`）

12枚の中から選んで答えを作ります。使わない文字も入っています。1枚は1回だけ使えます（答えに同じ字が2回あるときは、その字が2枚入っています）。

```json
"body": {
  "text": "ケチャップで炒めたスパゲッティで、日本の喫茶店の定番メニューになっているものは?",
  "panel": ["ケ", "ポ", "ン", "ク", "ト", "ル", "タ", "ス", "ピ", "メ", "リ", "ナ"]
},
"answer": "ナポリタン"
```

### 順番当て（`junban`）

`items` の4つを、問題文の順に並べたものが `answer` です。漢字4字を並べて四字熟語を作る問題も、この形式に入っています。

```json
"body": {
  "text": "次の国民的テレビアニメを、放送開始が早い順に並べてください。",
  "items": ["ちびまる子ちゃん", "サザエさん", "名探偵コナン", "クレヨンしんちゃん"]
},
"answer": ["サザエさん", "ちびまる子ちゃん", "クレヨンしんちゃん", "名探偵コナン"]
```

## そろえた版（`data/flat.jsonl`）

形式ごとに形が違うと読み込みにくい道具（Hugging Face の datasets など）向けに、どの問題も同じ項目にそろえた版です。`id`・`genre`・`format`・`difficulty`・`note`・`source_url`・`as_of`・`expires` は上と同じ（空は `""`）。`version` はありません。

| 項目 | 中身 |
|---|---|
| `question` | 問題文（連想は空） |
| `hints` | 連想のヒント5つ（ほかは空の配列） |
| `options` | 選択肢・文字・並べるもの |
| `answer` | 答え。○×は「○」「×」。順番当ては空 |
| `answer_order` | 順番当ての答えの並び（ほかは空の配列） |

## 表の版（`data/all.csv`）

| 列 | 中身 |
|---|---|
| `id`・`genre`・`format`・`difficulty` | 上と同じ |
| `genre_ja`・`format_ja` | ジャンルと形式の日本語の名前 |
| `question` | 問題文（連想は空） |
| `hints` | 連想のヒント5つを「 ｜ 」（全角の縦線）でつないだもの |
| `options` | 選択肢・文字・並べるものを「 ｜ 」でつないだもの。「｜」はデータの中に出てきません |
| `answer` | 答え。○×は「○」「×」、順番当ては並びを「 → 」でつないだもの |
| `note`・`source_url`・`as_of`・`expires` | 上と同じ（空は空欄） |

`version` はありません。文字コードは UTF-8（BOM 付き）です。

Excel で開くと、`id` が数字や指数（`2177474691093779`・`0020617036637e89` など）に化けることがあります。間違いを知らせるときに `id` を使うなら、「データ」→「テキストまたは CSV から」で読み込み、`id` の列を文字列にしてください。

## AI の評価に使うとき

AI に渡すのは `body`（そろえた版なら `question`・`hints`・`options`）だけにしてください。`answer`・`note`・`source_url` には答えや答えの手がかりが入っています。

同じ題材を別の形式で聞く問題もあります（同じ人物の四択と連想など）。学習用と評価用に分けるときは、`source_url` が同じ問題を同じ側にまとめると、答えを覚えただけの結果になりにくくなります。
